# ととのえ｜Totonoe

選択した日付を、いつもの書き方に揃える Chrome 拡張機能です。

```text
6/5              → 6月5日(金)
2026-09-21 14:30 → 9月21日(月) 14:30
明後日           → 2026/9/23(水)
```

出力書式は自由に変更できます。入力パターンも正規表現で追加・編集できます。

## 使い方

1. ページ上の日付を選択する
2. `Option + Shift + D`（Windows は `Alt + Shift + D`）を押し、表示されたメニューから書式を選ぶ
3. 入力欄では選択部分を置き換え、それ以外の場所では結果をクリップボードにコピーします

右クリックメニューの「ととのえる」から書式を選ぶこともできます。ショートカットキーは
`chrome://extensions/shortcuts` で変更できます。

選択範囲に日付が複数ある場合は、日付以外の文字や改行を残したまま一括で変換します。

```text
6/5  キックオフ       6月5日(金)  キックオフ
6/12 中間レビュー  →  6月12日(金) 中間レビュー
6/19 納品             6月19日(金) 納品
```

設定画面は、ツールバーのアイコンまたは右クリックメニューの「設定…」から開けます。

## インストール

### Chrome ウェブストア

現在、公開審査中です。

### GitHub Releases

1. [Releases](../../releases) から zip をダウンロードして展開する
2. Chrome で `chrome://extensions` を開く
3. 「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選ぶ

この方法でインストールした場合は自動更新されません。新しいリリースをダウンロードし直し、
`chrome://extensions` で拡張機能を再読み込みしてください。

## 対応している入力

- 年月日: `2026-09-21` `2026/9/21` `2026年9月21日`
- 月日: `6/5` `9-21` `6月5日`
- 相対表現: `昨日` `今日` `明日` `明後日` など
- 曜日つきの日付: `2026/9/21(月)` `6月5日（金曜日）` など
- 時刻つきの日付: `14:30` `14時30分` `午後2:05` など
- 半角・全角数字

年が省略されている場合は、今年の日付として扱います。

## 書式トークン

| トークン | 出力例 |
|---|---|
| `yyyy` / `yy` | 2026 / 26 |
| `M` / `MM` | 9 / 09 |
| `d` / `dd` | 21 / 21 |
| `ddd` / `dddd` | 月 / 月曜日 |
| `E` | Mon |
| `H` / `HH` | 14 / 14（24時間制） |
| `h` / `hh` | 2 / 02（12時間制） |
| `m` / `mm` | 30 / 30（分） |
| `a` | 午前 / 午後 |
| `[ ]` | 囲んだ文字をそのまま出力 |

たとえば `M月d日(ddd) H:mm` は `9月21日(月) 14:30` になります。
`M` は月、`m` は分です。

## プライバシー

ととのえは、選択した文字列の変換と設定の保存に必要な範囲で Chrome の権限を使用します。
閲覧履歴やページの内容を外部へ送信する処理はありません。

## 開発

ビルドは不要です。Node.js 20 以上でテストと配布用 zip の作成ができます。

```sh
npm test
npm run build
```

動作確認には [test/manual.html](test/manual.html) を使えます。ローカルファイル上で試す場合は、
拡張機能の詳細画面で「ファイルの URL へのアクセスを許可する」をオンにしてください。

### バージョンを更新する

次のコマンドで `manifest.json` と `package.json` のバージョンをまとめて更新します。

```sh
npm run bump -- 0.3.0
```

Chrome ウェブストアに提出するバージョンは、前回より大きい番号にする必要があります。

### リリースする

`manifest.json` と同じ番号のタグを push すると、GitHub Actions がテストを実行し、
配布用 zip を [Releases](../../releases) に追加します。

```sh
npm run bump -- 0.3.0
git add manifest.json package.json
git commit -m "v0.3.0"
git tag v0.3.0
git push origin main
git push origin v0.3.0
```

### Chrome ウェブストア公開後に更新する

1. 変更をローカルで確認し、`npm test` を実行する
2. `npm run bump -- 0.3.0` のようにバージョンを上げる
3. `npm run build` で `totonoe.zip` を作る
4. [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole/) で対象の拡張機能を開く
5. 「パッケージ」から新しい zip をアップロードし、「審査に提出」を押す
6. 審査通過後に公開する（自動公開または手動公開を選べます）

公開されるまでは以前のバージョンがそのまま利用されます。新しいバージョンが公開されると、
Chrome ウェブストアからインストールした利用者には自動で配信されます。権限を追加した場合は、
利用者による再承認が必要になることがあります。
